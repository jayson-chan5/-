# 软考经验总结
## 1.软考设计师（中级）
考试形式：基础知识+案例分析
### 1.课程学习
仅推荐王勇老师_软件设计师课，无需购买或学习其他课程.  
课程是比较久远版本，但经典永流传，Youtube上可以找到.  
### 2.刷题
手机端app软考通 或 pc端 软考达人  
### 3.备考
零基础备考：建议花上10天，5天听课（2倍速）并适当做笔记，5天刷题。  
视为期末考试即可，谁不是最后1-2周突击的啊~  

## 2.系统架构师（高级）
考试形式：基础知识+案例分析+论文  
#### 1.课程学习
基础知识和软件设计师考察高度重叠，有基础的话简单学学即可应付。  
仓库会提供相应备考资料，如果追求题目实时性，建议去pdd等购买网课（文老师案例和论文讲得很好）        

### 2.刷题
pc端 软考达人 体验更好  
### 3.备考
无开发经验备考，会有点难度，要**靠运气**，主要是**论文**环节。  
案例和论文一定要学习网课，建议文老师课程  
1）案例：做历5年真题并结合网课讲解  
2）论文：根据网课教学及真题分析，准备至少5篇不同主题目论文，熟练**背诵和码字**  
对无项目开发的群体而言，通过与否要靠点运气。若4道论文考到了未准备的主题，付出可能白费  

## 3.杂念与选科目
软件设计师视为大学期末考试对待就行，不同的是没有老师捞，只要学习态度没问题，基本就能过。  
系统架构师是本人在考完软件设计师后，同AI沟通确定的，它给出的理由是：学习内容重叠度高、脉络一致。  
但如果可以重来，我不会选它！希望保通过率的伙计慎选！  
首推项目管理，系统分析设计师也比架构师容易通过。
